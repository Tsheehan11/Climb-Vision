# climb-vision — v1.x Tasks

Status tracker for post-v1 work. Check items off as you go; add new ones
as testing surfaces them.

## Testing v1 on real footage
- [ ] Film 3-5 clips (tripod, side-on, full body in frame) — mix of sends and falls
- [ ] Run each through `main.py`, review annotated video for tracking quality
- [ ] Log flag accuracy per clip (timestamp, correct/false-positive/missed) in a simple sheet
- [ ] Tune `margin_ratio` in `features.py` based on false-positive rate
- [ ] Tune `min_duration_frames` based on noise vs. missed-flag tradeoff

## New heuristics (each follows the pattern in `features.py`: feature fn + violation detector)
- [ ] Hip rotation angle — detect flagging / twist-lock usage vs. square-on climbing
- [ ] Dead-point / contact-time analysis — how long a hand hovers before committing
- [ ] Fall/dismount detection — sudden vertical hip-velocity spike, for auto-segmenting
      a longer recording session into individual attempts

## Pipeline robustness
- [ ] Handle multi-person frames gracefully (currently takes first detected person only —
      fine solo, but confirm no false pickups from people in the background)
- [ ] Add a `--model full` / `--model lite` flag to swap pose_landmarker variants
      for accuracy vs. speed tradeoff
- [ ] Decide on a confidence threshold policy for frames with partial occlusion
      (e.g. a foot blocked by a hold) rather than silently dropping the landmark

## v2 — handheld camera support
- [ ] Prototype optical-flow-based motion compensation (`cv2.calcOpticalFlowPyrLK`)
- [ ] Evaluate anchoring to fixed holds vs. general wall-texture flow
- [ ] Validate that normalized (body-scale-relative) features already absorb
      most of the handheld noise before adding full stabilization

## v3 — ML layer (once there's enough labeled footage)
- [ ] Decide on labeling scheme (per-move good/bad, or per-fault-type)
- [ ] Build minimal labeled dataset from testing-loop clips
- [ ] Train small classifier (MLP or 1D-CNN over joint-angle time series)
- [ ] Compare classifier flags against the v1 rule-based heuristics on held-out clips
